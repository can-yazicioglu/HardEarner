# Changes

## 2.16.0 — Research Lab and a calmer workspace

- Add saved desktop/mobile dashboards, a 44-entry tool library, 38 optional widget definitions, seven starter templates, encrypted notebooks and a guided learning path. Catalogue entries include explicit setup states, not a claim that every integration is live.
- Add 1–8 saved chart layouts with synchronization and shared streams; preserve drawings, execution markers and existing workflows.
- Add relative-performance, cycle, return, options, sequenced order-book, SEC, DeFi/yield and flow research with source/time/unit labels, scenario calculators and supported metric alerts.
- Add documented FRED, FMP and DefiLlama Pro routes and expand the remaining-access list. No paid subscription is purchased or missing data fabricated.
- Make black the default, add a top-right light-theme control and reduced-motion-aware transitions, retaining Cherry Red accents.
- Open Research from an unlocked parent without a second password through an exact-origin, one-use in-memory handoff. Explicit lock still locks related tabs; direct visits and refreshes require unlock.
- Update Learn FAST and document feature-by-feature coverage, calculations and remaining implementation.

Desktop, private web and source use 2.16.0. Store certification and installation remain separate stages. See [verification](docs/releases/2.16.0.md).

## 2.15.0 — Market intelligence, in Cherry Red

- Extend Research with optional funding, open interest, observed liquidations, whale activity, ETF flows and on-chain valuation panels. Reuse asset search, favourites and charts without changing portfolio calculations.
- Show Bybit settlement intervals, source timestamps, units, history limits and observed-session coverage. Keep modelled liquidation heatmaps separate from actual received events.
- Add public Hyperliquid address observations, persisted size changes, evidence links and filters. Transfers are never assumed to be trades.
- Add personal CoinGlass and Glassnode adapters with encrypted keys and clear plan/configuration states. These paid feeds require each user's permitted provider access; they are not bundled subscriptions.
- Add metric reminders with duplicate prevention, cooldowns, stale-data protection and retained trigger history. Existing price alerts remain intact.
- Replace the primary navy theme with Cherry Red, retain the logo design, and prevent bright Research frame/loading backgrounds.
- Extend Learn FAST, privacy notices and provider documentation. Keep desktop and web storage/privacy behaviour intact.

Windows, private web and source use version 2.15.0. Store certification and installation are separate from source publication and web deployment.

## 2.14.0 — Research workspace

- Open a dedicated HardEarner Research window or browser tab with overview, charts, screeners, news, notes and alerts.
- Add crypto rankings, dominance, market-cap breakdowns, stablecoin supply, TVL, movers, trends, heatmaps, economic calendar and source-linked collections.
- Restore useful initial precious-metal charts with daily gram history; offer observed spot sessions and separate intraday TradingView charts for all four metals.
- Show exact recorded executions and fees when hovering or tapping purchase/sale markers.
- Preserve tiny connected balances in totals while grouping them behind a reversible Holdings display filter. Prevent purchase history from recreating zero-balance assets.
- Give Stocks & funds a distinct building icon and update Learn FAST in English and Turkish.
- Isolate public embedded widgets from the encrypted vault and protect stream ownership across native windows.

The Windows package, private-web build and repository share version 2.14.0. Store availability depends on Microsoft certification; a source tag does not imply the installed app has updated. Web and Windows storage remain separate, and web alerts require a visible, online, unlocked page.

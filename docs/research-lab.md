# Research Lab · 2.16

Research Lab extends the existing Research window; Overview, personal charts, market widgets, screeners, drawings, executions and alerts remain in place. The 44-entry library and 38-widget catalogue are an index of available tools **and explicitly marked setup states**, not a claim that 44 complete external products or 38 live datasets have been reproduced.

The owner's supplied 107-page NinjaTools guide and accompanying brief informed the feature inventory. The interface, calculations and explanatory copy are HardEarner's implementation; third-party branding, paid data and proprietary content are not copied.

## Start here

1. Open **Self Analysis → Research Lab** from an unlocked app. The main login is enough for this action.
2. Start with **My dashboard → Minimal**. Add only useful widgets; move them by dragging or the arrow buttons, and resize them. Phone and desktop widget arrangements are saved separately.
3. Use **Tool library** to find a subject. The shared asset picker and favourite button still apply. Each result carries its source, units, observation time or an explicit missing-time label, retrieval time and coverage.
4. Save up to 20 named dashboards. Layout JSON exports contain layout preferences only. Project notes, public watch addresses and provider keys stay inside the encrypted vault.
5. **Charts** supports 1, 2 side-by-side, 2 stacked, 3, 4, 6 and 8 charts. Save named configurations, synchronize symbols/intervals/visible ranges, reorder or expand panels. Offscreen charts pause rendering; identical feeds share one connection.
6. Use the sun/moon button at the top right. Black is the default; light mode is optional. Transitions respect the operating system's reduced-motion preference.
7. **Research starter guide** has seven steps and 27 short concepts. Main **Learn FAST** now includes dashboard, evidence, model and appearance lessons.

## Calculations and interpretation

- Missing, whitespace, boolean, non-finite or malformed numeric fields never become zero. An actual reported zero is retained.
- ALT/BTC relative return is `(1 + alt return) / (1 + BTC return) - 1`; it is not simple subtraction. Only aligned source timestamps enter breadth. Current top-100 membership introduces survivorship bias.
- Bands require consecutive completed UTC daily observations. Pi is 111-day SMA versus twice 350-day SMA. Golden bands use 350-day SMA times 1.6/2/3/5/8/13/21; two-year bands use 730-day SMA and five times it. They are historical references, not forecasts.
- Quarter/year returns compound constituent returns. Partial current or missing-boundary periods remain incomplete.
- DCA uses the first available observation on/after each planned date. Every 30 days is labelled as such, not a calendar-month schedule. Dated FX uses a preceding business-day observation at most seven days old. Fees reduce acquired units; both DCA and lump-sum scenarios use the same price/FX endpoints.
- Option OI already uses the underlying coin units. Max pain is calculated independently for one expiry. Greeks assume European Black–Scholes, constant IV/rates and no exchange-specific settlement model. Signed gamma assumes positive call and negative put OI, **not known dealer positions**. Gamma flip is shown only for a unique crossing in the sampled 60–140% spot range. Skew requires strikes near +/-0.25 delta within 0.10.
- SEC modern 13F XML reports dollars; pre-3 January 2023 legacy thousand-dollar filings are rejected by this adapter. Missing previous reports do not imply a purchase. Amendments are flagged rather than silently merged.
- FRED net liquidity is `WALCL - WTREGEN - 1000 * RRPONTSYD`, all displayed in USD millions, on shared observation dates. SOFR minus IORB is percentage points. The dollar series is a broad trade-weighted index, not DXY. BTC correlation compares log returns (%) with absolute native-unit macro changes, minimum six changes, gaps at most 45 days, rolling window up to 30 **observations**, not days. Latest-vintage data is not a point-in-time backtest.

All new requests use fixed allowlisted routes, reject redirects, time out after 20 seconds and cap parsed response size. 429 responses pause that provider for 60–3,600 seconds using Retry-After where present. Identical in-flight queries coalesce. Public caches are bounded; licensed results are not globally shared between users. Keys use the existing encrypted storage and authenticated relay, never client bundles or result metadata. Third-party widgets receive public symbols, not holdings or keys.

## Alerts, storage and session boundaries

Existing metric alerts now also cover Mayer, premium, Fear & Greed, option put/call OI, daily volume/baseline, relative breadth, stablecoin supply and SOFR/IORB spread. They use existing threshold-entry detection, duplicate prevention, cooldown, pause/resume and history. Missing, incomplete or stale observations cannot trigger. This is not arbitrary alerting on every table column; unavailable provider features stay unavailable.

Research data keys, notebooks, layouts, addresses and alerts use the existing encrypted Research store. A Windows upgrade backup is taken before loading. Neither the portfolio schema nor the connected-account ledger changes in this release. Presentation theme alone lives in localStorage.

On the web, an unlocked parent opens one exact same-origin Research child with a one-use, 15-second handshake. Exact origin, child window, random token, account identity and vault salt are checked. A non-extractable CryptoKey passes through MessageChannel in memory; password, holdings and key bytes are not written to URLs, localStorage or BroadcastChannel. The child decrypts its own authenticated vault response. Explicit lock and successful password rotation lock the account's other tabs. Refreshing/directly opening a tab still requires login; this is not a persistent unattended login. A blocked popup produces the existing retry guidance.

## Remaining access and implementation

The setup screen lists CoinGlass, Glassnode, a free FRED key, FMP calendar, DefiLlama Pro, public Hyperliquid addresses and optional CoinGecko Demo access. It also lists broader stock/sector ETF net-flow licensing, verified burn/buyback feeds, geopolitical/news data, LLM consent/provider setup, and commercial display rights.

An API key alone will not complete the **pending** scope in the coverage ledger. Cross-provider news/event aggregation, comprehensive age-cohort heatmaps, multi-manager overlap, bridge-anomaly scoring, broad sector ETF flows and automated LLM bulletins need further implementation and validation. No purchase, automatic trading, paid subscription, news scraping or financial-account migration is performed by this release.

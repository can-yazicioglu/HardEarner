Help and support

Start with Learn FAST or FAQ inside the app. For a connection problem, check the provider's API permissions and the latest sync error. For a replaced Kraken key, use Accounts → Kraken → Manage → Update API key.

Contact the developer, Can Yazicioglu, at can.yazicioglu.p@gmail.com. Include the app version and steps to reproduce the issue. Never send passwords or API secrets.

Windows privacy notice · Web/mobile app

Portfolio estimates and analysis tools are informational. Provider coverage and data delays vary. HardEarner cannot place trades or move money.

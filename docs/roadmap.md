# Roadmap

HardEarner's vision is a simple place to manage a financial life spread across accounts and physical assets. The current product is a private, read-only portfolio and analysis workspace.

## In the current source snapshot

- [x] Windows application and responsive private website sharing the core UI.
- [x] Manual/physical holdings alongside supported account balances.
- [x] Purchase logs, cost provenance, conversion evidence and fees for supported histories.
- [x] Daily performance records and per-asset views.
- [x] Chart drawings, streamed crypto updates, markers and price alerts.
- [x] Stocks, ETFs and fund research with source-labelled data.
- [x] Invited web accounts, encrypted per-user vaults, browser sync and recovery.
- [x] English/Turkish and additional language selections, with in-app learning material.

## Next priorities

- [ ] More complete, independently verified history coverage for each connector.
- [ ] Reconciliation tools that clearly explain unmatched transfers and missing costs.
- [ ] A reviewed migration and sync path between installed Windows data and web vaults.
- [ ] More instrument, exchange and wallet-network coverage with accurate limitations.
- [ ] Better onboarding, translation coverage and accessible mobile workflows.
- [ ] Server-backed alert delivery that works when the browser is closed.
- [ ] Additional authorised banking/broker partnerships and production access.

## Longer-term exploration

Buying, selling and account-to-account transfers belong to a separate phase. They require provider agreements, appropriate permissions, order/payment review, failure recovery and regulatory assessment. These are product goals, not features available in the current app.

No date or provider commitment is implied by this list. Reliability, user control and understandable financial records come before expanding the feature count.

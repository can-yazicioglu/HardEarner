# 2.16.1 verification

Validated on 10 October 2026. Source, desktop and private-web version: **2.16.1**; Windows package version: **2.16.1.0**.

## Changes

- Private web: **Forgot your password / Şifremi unuttum**, verified-email delivery of an eight-digit code, new-password confirmation and normal sign-in afterward.
- Reset explicitly starts an empty vault. The previous ciphertext is archived in the same atomic transaction and can be downloaded from Settings. It still requires the old password; no encryption-key escrow or hidden recovery backdoor was added.
- Ten-minute code expiry, five attempts, persistent resend budgets, account/revision binding, idempotent exact retries, safe delivery errors and a completion notification. Existing device conflict protection and Research locking remain intact.
- Turkish instructions, phone layout, updated web Learn FAST, privacy/security documentation and the desktop FAQ's web-versus-local-password explanation.

# 2.15.0 verification

Validated on 6 October 2026. The source, Windows payload and private web build use 2.15.0.

- Both production bundles built successfully.
- 206 desktop/core and 22 Worker/security tests passed.
- Five browser suites passed in Chromium and WebKit (10 runs). Tests include four responsive widths, Turkish copy, provider failures, encrypted vault reload/restore and cross-device conflict handling.
- Three isolated Electron workflows passed: existing portfolio/charts/alerts, investments, and the new Research IPC/credentials/reminders. Synthetic profiles only; no personal accounts were modified.
- Live Bybit funding and open-interest histories returned BTC, ETH and SOL values with provider timestamps. The liquidation socket subscribed successfully; no events were observed during the short probe. Event direction, duplicate handling and reconnects were tested with fixtures.
- Hyperliquid's public endpoint returned a valid empty-address response. Non-empty position changes were tested with fixtures, not a user's live positions.
- Live TradingView stock, crypto, calendar and chart embeds were checked in a light browser preference and rendered their dark theme.
- CoinGlass and Glassnode are documented, optional adapters. No paid API key was available; no claim of live paid-data verification is made.
- MSIX semantic validation passed; no user data or test credentials are bundled. Store certification and installation remain separate from these checks.

See [provider access and limitations](../research-data.md). Desktop and private-web data storage remain separate; browser devices share their invited account's encrypted vault.

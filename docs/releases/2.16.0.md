## Access and remaining scope

No live CoinGlass, Glassnode, FRED, FMP or DefiLlama Pro credentials were supplied for this release. Their configuration/error contracts are tested; paid routes must be verified with the relevant entitlement before claiming live operation. Public Hyperliquid watch addresses must be supplied by the user. Commercial display and redistribution permissions remain separate from API access.

Licensed news aggregation, broad stock/sector ETF net flows, verified burn/buyback events, geopolitical scoring, comprehensive UTXO age-band maps, multi-manager overlap, bridge-anomaly scoring and automated LLM bulletins still need the work described in the coverage ledger. A catalogue/configuration card is not a completed live feature.
